## Goal

Implement WSLX-002 — PathX, the first real WSLX feature command.

PathX converts between Windows and WSL path formats and provides automatic
direction detection plus explicit conversion modes.

## Command Contract

Automatic conversion:

```bash
wslx path 'D:\Programming\Test'
wslx path '/mnt/d/Programming/Test'
```

Explicit conversion:

```bash
wslx path --to-wsl 'D:\Programming\Test'
wslx path --to-windows '/mnt/d/Programming/Test'
```

Help:

```bash
wslx path --help
```

## Why

WSLX needs a tested path-conversion command before higher-level features such
as open, smart-cd, and execution wrappers can reuse path translation.

Conversion is delegated to WSL's native `wslpath` utility.

WSLX adds direction detection, explicit modes, validation, consistent errors,
help, automated tests, installed packaging, completion, and documentation.

The README was simplified into a short user guide focused on cloning,
installation, PathX usage, updating, and uninstalling WSLX.
