
# WSLX-003 — CD / WCD

Timestamp: 2026-09-08T07:30:47+03:00

## Goal

Add safe current-shell navigation for Windows, WSL, and relative paths.

## Core design

```text
parent Bash
  -> child WSLX computes normalized path
  -> child exits
  -> parent Bash runs builtin cd
  -> Bash uses chdir(2)
  -> same parent shell continues in the new directory
```

The child never changes the parent.

## Validation

```bash
make check
NO_COLOR=1 make check
git diff --check
git status -sb
```
