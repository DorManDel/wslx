# WSLX-002 — Path Interop

Timestamp: 2026-09-08T01:05:32+03:00
Version: 0.1.0-dev

## Goal

Add the first real WSLX interoperability feature: predictable path handling
between Windows and WSL.

## Final command contract

Default output is usable in WSL:

```bash
wslx 'D:\Programming\Test'
wslx path 'D:\Programming\Test'
# /mnt/d/Programming/Test
```

A WSL path stays in WSL form. Windows output and interactive link presentation
are explicit:

```bash
wslx --win <path>
wslx --link <path>
```

## Semantic decision

The original opposite-direction auto-conversion was replaced before merge.
WSLX runs in WSL, so the useful default is:

```text
Windows input -> WSL form
WSL input     -> unchanged
```

`--win` returns clean Windows text. `--link` is presentation-only and falls back
to plain Windows text when output is captured.

## CLI language

- canonical commands use `wslx <command>`;
- names are short lowercase familiar actions;
- readable long options are preferred;
- `w<command>` shortcuts are reserved for frequent future actions such as
  `wcd` and `wopen`;
- command contracts are defined before implementation in `docs/COMMANDS.md` and
  use the template in `docs/commands/README.md`.
