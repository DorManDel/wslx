# Command Explanation Documents

Every real WSLX command gets one teaching-oriented document here.

Required sections for a command document:

1. Purpose — why the command exists.
2. User interface — syntax and options.
3. Examples — representative safe uses.
4. Execution flow — step-by-step behavior.
5. Dependencies — external programs/APIs used.
6. Functions — each internal function and responsibility.
7. Line-by-line walkthrough — detailed learning notes.
8. Error handling and exit codes.
9. Edge cases.
10. Tests.
11. Future improvements.

The first file will be `path.md` in WSLX-002.
